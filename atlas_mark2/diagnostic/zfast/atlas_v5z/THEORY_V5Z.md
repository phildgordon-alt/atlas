# atlas_v5z: atlas_v5 with zfast as the Z and row provider (written before any v5z run, 2026-10-19)

**What it is.** atlas_v5z certifies exactly atlas_v5's claim with exactly atlas_v5's logic. It is THEORY_V5.md (copied unchanged in
`frozen_ref/`) with the following changes:
- **Change 1:** the Hardy Z enclosures come from zfast;
- **Change 2:** the k = 0 row jet Re(−ζ′/ζ)(1/2 + π/(2a) + ix) comes from zfast instead of Arb;
- **Changes 3–4:** a no-deletion policy and a provenance field.

Nothing else changes: the LP, the S-layer, the tiling, the Lean export, every inequality, and every other Arb evaluation (θ in the
counts, the far bounds, arch, the prime sums S_M, pole/const).

## 1. Trust-base change

**Old trust base.** v5 trusted Arb's ζ(1/2 + it) (Riemann–Siegel with the Arias de Reyna remainder) and Arb's length-2 ζ series.

**New trust base.** v5z trusts zfast (`zfast/bin/libzfast.v10b.dylib`, sha 3daa33d5…, sources in `zfast/bin/src_v10b/`) for these two
quantities only:
- **Z(T0 + u):** a ball from an M3 window session (THEORY_M3.md):
  - bucketed Taylor moments of the main sum (Lemmas M1 and M2);
  - exact fixed-point phases (THEORY_ZFAST §5);
  - the cos/sin kernel (§6);
  - θ and the RS correction from Arb [A] (§3–4);
  - per-point subtraction for N(t) < N_w.
- **Rows:** ζ(s) and ζ′(s) from a row session (THEORY_M3 §1–3 and THEORY_ZFAST §10, with H, H′ and χ from Arb [A]), giving
  Re(−ζ′/ζ).

**Sessions.** The centre is c = 6·round(u/6) and the half-width is H = 3. |u − c| ≤ 3 is asserted for every query. Every ball
returned is a valid enclosure whichever session produces it, so caching affects cost only.

**Validation evidence (zfast RESULTS_M2.md and RESULTS_M3.md):**
- 208/208 single points inside Arb at 10¹⁰–10¹⁶;
- 300/300 session points against single points;
- 136/136 session points inside Arb;
- N-jump windows 40/40;
- rows 38/38 inside Arb's v5 jet;
- 94/94 certified sign changes of the 10¹⁵/10¹⁶ record windows reproduced;
- agreement with Arb at 10¹⁸ and 10²⁰.

The radii are about 1e-10 for Z and about 1e-12 for P.

**Interface.** `lib/zfast_provider.py` is new and trusted. It:
- asserts the library sha;
- calls the C API;
- parses Arb-printed enclosures with arb(str).

## 3. Acceptance protocol (PREDICTIONS_M4.md)

1. **Control** [10¹², 10¹² + 2] (inside Platt–Trudgian), parameters as in v5.
2. **Re-certify** with the parameters of the original runs:

   | window | zs-step | original run |
   |---|---|---|
   | [10¹³, +2] | 0.005 | atlas_v5/runs |
   | [10¹⁴, +2] | 0.005 | atlas_v5/runs |
   | [10¹⁵, +2] | 0.01 | record_heights/v5run |
   | [10¹⁵ + 286, +288] | 0.01 | record_heights/v5run |
   | [10¹⁶, +2] | 0.02 | record_heights/v5run |

   **Required in every window:**
   - closed (A) and (B);
   - the same number of sign changes in the target as the original (which equals Arb's Turing count);
   - every v5z sign-change interval in the target intersects exactly one original interval, one to one;
   - plain and hardened replay plus an independent replay;
   - 0 tiling seams;
   - a Lean audit with 0 violations.

   min_candidate_lower may differ slightly: the rows' Elo/Ehi move by at most about 1e-11. It is reported.
3. **Only then:** new windows [10¹⁷, 10¹⁷ + 2] and [10¹⁸, 10¹⁸ + 2], pre-registered. Arb's Turing count is the diagnostic where it
   fits under the 1 GB watchdog; otherwise it is reported as unavailable.
